# Mobile-Plan: #279 — Feiertage pro Bundesland im Dashboard
Research: mobile/thoughts/279-research.md (inkl. "Entscheidungen zu den offenen Fragen")
Koordination: thoughts/279-coordination.md (PR 2, "Refs #279", nach Backend-PR 1)

## Ziel
Das Bundesland wird je Arbeitszeit-Profil gespeichert und über `ApiDataSource.saveSettings` nach Firestore synchronisiert. Das Dashboard zeigt oberhalb des Timers einen rein informativen, übersetzten Hinweis "Heute ist Feiertag: …", wenn heute laut Bundesland ein Feiertag ist. Reports-Logik und `getGermanHolidayNames` bleiben unverändert.
